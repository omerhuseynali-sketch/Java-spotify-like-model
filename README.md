# MiniSpotify 🎵

A basic Java project built to practice Object-Oriented Programming (OOP) concepts.

## Features
* **Inheritance:** A superclass `Content` extended by `Song` and `Podcast` subclasses.
* **Polymorphism:** Managing a mixed playlist of songs and podcasts seamlessly.
* **Type Safety:** Using `instanceof` and casting to access specialized media details.
